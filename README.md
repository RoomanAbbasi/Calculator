# 🧮 Calculator

A minimal dark-themed calculator built with HTML, CSS and vanilla JavaScript.

## Features
- Add, subtract, multiply, divide
- Percent, delete and clear
- Full keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Shows the previous expression above the result
- Handles divide-by-zero

## How to Run
Download all 3 files (`index.html`, `style.css`, `app.js`) into one folder and open `index.html`.

## Tech Stack
HTML5 · CSS3 · JavaScript
